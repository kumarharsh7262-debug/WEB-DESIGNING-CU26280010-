# Lab Sheet 6 - Portfolio Website

Open `index.html` in any browser. No build step or internet needed.

## Structure
```
portfolio/
  index.html      Home
  about.html      About
  projects.html   Projects
  contact.html    Contact
  css/style.css   All styles (external CSS)
  js/main.js      All interactivity
  images/         SVG images
```

## Task map
| # | Task | Where |
|---|------|-------|
| 1 | Multi-page, semantic HTML5 | all 4 pages (header, nav, main, section, article, footer) |
| 2 | External CSS, Flexbox nav and card grids | style.css: Header/Navigation, Card grid |
| 3 | Hero banner, overlay, CTA | index.html `.hero`; style.css Hero |
| 4 | Hamburger menu | main.js Task 4; style.css `.hamburger` |
| 5 | Grid gallery with hover zoom | about.html `.gallery`; `transform: scale()` |
| 6 | Contact form validation | contact.html; main.js Task 6 |
| 7 | Dark / light toggle | header button; main.js swaps `:root` variables |
| 8 | Pricing table | index.html `#pricing` |
| 9 | Smooth scroll links | index.html quick links; main.js Task 9 |
| 10 | FAQ accordion | index.html `#faq` |
| 11 | Testimonials carousel | index.html `#testimonials` (JS array, opacity fade) |
| 12 | Footer with social icons | all pages |
| 13 | Back to top button | all pages |
| 14 | Media queries | style.css Responsive (992, 768, 480 px) |
| 15 | Stats counter | index.html `#stats` (IntersectionObserver) |
| 16 | Feature grid with SVG icons | index.html `#features` |
| 17 | Modal popup | index.html (Hire Me / Choose Plan buttons) |
| 18 | Print styles | style.css `@media print` |
| 19 | Project search filter | projects.html |
